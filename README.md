# match_reports

One match, one question, every Friday: a short tactical report in English, with a Spanish version.

Read them on Substack: [Match Notes](https://ivancalvorodriguez.substack.com/) (English) · [Notas de partido](https://ivancalvorodriguezes.substack.com/) (Spanish).

Each `week_N/` folder holds that week's report; `plantilla-informe.md` is the template.
